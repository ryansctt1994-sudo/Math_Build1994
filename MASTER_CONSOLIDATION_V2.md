# Weaver Auto Scientist — master consolidation v2

The new implementation lives in `packages/auto-scientist/`, alongside the
existing Lean project. It consumes the assurance core from
`ryansctt1994-sudo/Weaver_Os`.

The package enforces an explicit research lifecycle, bounded experiment
execution, receipt-backed replay, strict Lean checker status, seed-matched
benchmark comparison, falsifiable claim records, and a distinct-witness gate
for E4 promotion.

Missing proof tooling is reported as unavailable, never verified. Heuristic or
demo fallbacks cannot create proof evidence, and local replay is not labeled as
independent reproduction.
